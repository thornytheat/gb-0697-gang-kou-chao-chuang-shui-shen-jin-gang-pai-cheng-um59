# 潮窗字段

id保持字符串。kind取tide、ship、pilot、block、team、receipt。start/end带时区；统一UTC秒。tide的value为潮高；ship为吃水；m/cm统一为m。ship的aux为通航分钟。team为班组值守班次，receipt为通航回执；二者只用起止时刻，value/unit不参与业务，aux对team为可读班名。version为递增版本，采用同ID最高版；同版多条隔离。潮位乱序按时间排序。

基准水深8m，安全余量1m，要求潮高>=吃水+1-8。相邻潮位最长允许3小时插值；缺口不外推。航道区间为半开，结束同刻可开始下一航次。引航窗口须覆盖整个航次。排程按最早申请时间、船舶ID确定先后，采用最早可行窗。并非全局最优调度。

业务ID按kind命名空间隔离。同一UTC时刻的潮位不同值全部隔离为TIDE_TIME_CONFLICT，不能用其中任意值开启安全窗；同值重复仅保留编号最小者。

冲突潮位时刻保留为插值断点，相邻有效观测不能跨越该时刻推算安全窗。

## 班组工时

- `team` 班次重叠时归属不唯一：按开始时刻保留先者，后者隔离为 `TEAM_SHIFT_OVERLAP`。
- `receipt` 的 id 须对应一条 ship 申请，否则隔离为 `RECEIPT_UNMATCHED`。
- 航次工时 = 排程时段与班次的交集；回执到达后改用实际时段。不在任何班次内的部分记“未值守”，不计入班组。
- 暂计按排程记，实结按回执记；未回执航次保持暂计，二者分别汇总。
- 更正补差：同航次最高版回执与上一版回执逐班组比；首份回执与排程基线比。
- 已核准工时入持久台账，以航次+班组+回执版本幂等；退回不删除已核准记录。
